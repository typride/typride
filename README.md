## Notes

1. Random sample of 911 GitHub accounts read through the GraphQL API on 2026-10-06: 87% had zero contributions in the prior year, and among the 115 active accounts the median was 9, the 95th percentile 766 and the 99th percentile 4,385. For scale, GitHub reported about 1.1 billion public contributions across 180 million developers in 2025 ([Kinsta](https://kinsta.com/blog/github-statistics/), [Panto](https://www.getpanto.ai/blog/github-statistics)).
2. Public contribution graphs for the 365 days ending 2026-10-06. Private work only shows when an account opts in, so these undercount people whose day job is in private repos. Kent C. Dodds (10,379) and Mitchell Hashimoto (8,141) were well ahead; Evan You (2,812) and Dan Abramov (913) were behind.
3. The rank in [github-readme-stats](https://github.com/anuraghazra/github-readme-stats/blob/master/src/calculateRank.js) is a weighted percentile: stars 4, pull requests 3, commits 2, issues 1, reviews 1, followers 1. This account's 5 stars and 3 followers pull a lot of private activity down to the 43rd percentile. The same activity with 500 stars would be an A+.
