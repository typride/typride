## Notes

1. Random sample of 2,248 GitHub user accounts read through the GraphQL API on 2026-11-04, drawn from 30 random points across the whole user-ID range (1 to about 352 million). 973 had at least one contribution in the prior year. Among them the median was 1, the 95th percentile 77, the 99th percentile 704, and the highest 3,145. Accounts created in the last couple of years are mostly active but tiny (median 1), so the zero share fell to 57% from the 87% an October sample of older accounts found; among those older accounts alone the 99th percentile was 2,484. For scale, GitHub reported about 1.1 billion public contributions across 180 million developers in 2025 ([Kinsta](https://kinsta.com/blog/github-statistics/), [Panto](https://www.getpanto.ai/blog/github-statistics)).
2. Public contribution graphs for the 365 days ending 2026-11-04. Private work only shows when an account opts in, so these undercount people whose day job is in private repos. Kent C. Dodds (12,620), Mitchell Hashimoto (8,547) and Evan You (4,996) were ahead; Dan Abramov (877) was behind.
3. The rank in [github-readme-stats](https://github.com/anuraghazra/github-readme-stats/blob/master/src/calculateRank.js) is a weighted percentile: stars 4, pull requests 3, commits 2, issues 1, reviews 1, followers 1. This account's 6 stars and 8 followers pull a lot of private activity down to the 43rd percentile (recomputed 2026-11-04). The same activity with 500 stars would be an A.
